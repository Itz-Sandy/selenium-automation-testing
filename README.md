# Selenium Automation Testing

## Project Overview
Automated web testing using Python, Selenium WebDriver, and Pytest.

## Website
https://the-internet.herokuapp.com/

## Automated Test Cases
1. Checkbox selection
2. Dropdown selection
3. Login validation
4. JavaScript alert handling
5. Dynamic content loading

## Technologies
- Python
- Selenium WebDriver
- Pytest

## Installation
pip install -r requirements.txt

## Run Tests
python -m pytest -v test_automation.py
